OPERATING SYSTEMS VIVA SURVIVAL GUIDE

1. FIRST-COME, FIRST-SERVED (FCFS)

Non-preemptive FIFO queue. Processes run in chronological arrival order. Simple, zero context-switch overhead, but suffers from the Convoy Effect when heavy CPU jobs block light I/O tasks.

2. SHORTEST JOB FIRST (SJF / SRTF)

Selects process with minimal CPU burst. Provably optimal for minimizing average waiting time. Preemptive version is Shortest Remaining Time First (SRTF). Main flaw: Starvation of long CPU jobs.

3. PRIORITY SCHEDULING & AGING

Highest priority (lowest integer value) dispatched first. Solves real-time OS dispatching. Solves starvation using Aging: waiting tasks gradually receive priority promotions over time.

4. ROUND ROBIN (RR)

Designed for time-sharing. Each ready task gets a time quantum q before being re-enqueued. High responsiveness. Weakness: Excessive context switching if q is too small.

5. MULTI-LEVEL FEEDBACK QUEUE (MLFQ)

Production OS scheduler (Solaris, BSD, Windows, macOS). Features multiple priority tiers (Q0, Q1, Q2) with diminishing quanta. Periodic all-jobs boost eliminates starvation.
